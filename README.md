# AI Search Agent using n8n
An AI-powered internet search assistant built using n8n, Google Gemini, and SerpAPI.

## 🚀 Features
* Real-time internet search using SerpAPI
* AI-powered responses using Google Gemini
* Conversational AI agent workflow
* Memory support for better interactions
* Automated workflow using n8n
* Fast and intelligent search summarization

## 🛠️ Technologies Used
* n8n
* Google Gemini API
* SerpAPI
* AI Agents
* Workflow Automation
* REST APIs
*
